# 中国象棋 (Chinese Chess / Xiangqi)

完整的中国象棋小游戏，Python + pygame 实现，带内置 AI 对手。界面是**简易大字体版**：整块棋盘占满画面，顶部一行大字提示、棋盘下方一块能上下翻的棋谱记录，所有按钮收进一个「暂停」菜单，没有侧栏。**默认全屏启动**，布局随屏幕分辨率自动放大，棋盘、按钮、字号同步变大。

![python](https://img.shields.io/badge/python-3.15-blue) ![pygame](https://img.shields.io/badge/pygame--ce-2.5.8-green)

## 运行

```bash
python xiangqi.py
```

或直接运行已打包好的 `dist/xiangqi.exe`（桌面快捷方式「象棋游戏」）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `xiangqi.py` | 图形界面（简易版）：大棋盘、大字提示、棋谱面板、暂停菜单、存读棋局 |
| `xiangqi_rules.py` | 规则引擎：走法生成、攻击判定、局面评估、AI 搜索、中文记谱 |
| `xiangqi_full.py` | 旧版界面：带右侧栏、走法记录与难度按钮，`python xiangqi_full.py` 可运行 |
| `uifont.py` | 中文字体解析，各游戏共用；找不到时用程序自带的字体兜底 |
| `fonts/` | 随包携带的中文字体子集（Noto Sans SC，SIL OFL 协议） |
| `xiangqi.spec` | PyInstaller 打包配置 |
| `xiangqi.ico` | exe 图标（红边「帅」棋子），由 `tools/build_icon.py` 生成 |
| `test_xiangqi_rules.py` | 规则引擎测试（72 项） |
| `test_xiangqi_ui.py` | 界面交互测试（84 项，无头模式） |
| `test_uifont.py` | 中文字体测试（模拟没装黑体的电脑） |

## 中文字体

界面所有中文都由 `uifont.py` 负责渲染。程序按顺序找字体：

1. 程序自带的 `fonts/NotoSansSC.ttf`，粗体用 `fonts/NotoSansSC-Bold.ttf`
2. 系统里装的中文字体（微软雅黑、黑体、Noto Sans SC 等）
3. 系统字体目录里直接按文件名找

每个候选都会被**实际渲染几个汉字来验证**，只有真能画出字形的才会被采用。
这样在没装黑体的电脑上也不会出现满屏方框。

如果真的一个中文字体都找不到，屏幕顶部会挂一条红色提示条，说明字体出了什么问题。

## 界面

- **默认全屏**：按桌面实际分辨率排版，棋盘、按钮、字号全部同比放大；宽屏时整列垫一块浅色卡片，左右不再空荡。
- 顶部白色横幅：大字显示「你的回合（红方）」「电脑思考中，请稍候」「轮到黑方走棋」，下面一行小字给出操作指引或「已走 N 手」。
- 横幅右上角一个「暂停」按钮（`Esc` 也能叫出菜单）。
- 中间整块棋盘：格子随屏幕自动放大，棋子直径约格子的 88%，字号约 52%。
- **棋盘下方是棋谱记录**：每一步显示「序号 + 红/黑标签 + 记谱」，吃了子会写「吃X」；用鼠标滚轮或面板右上角的 ▲ ▼ 上下翻，新局自动清空。
- 暂停时棋盘会变暗，中间弹出一个面板，里面装着所有按钮：
  - 第一排：新 局 / 悔 棋 / 提 示（点完这三个蓝色按钮会自动关掉菜单回到棋盘）
  - 第二排：难度 / 对战方式 / 音效 / 全屏（显示当前状态，菜单保持打开方便看结果）
  - 第三排：继 续 / 退 出
  - 面板底部还有一行操作说明（快捷键）
- 选中的棋子有黄色粗圈，可落点画黄色大圆点，上一步用蓝框标出，被将军的将帅套红圈。
- 终局时棋盘中央弹出大号结果面板。

## 保存 / 读取棋局

- 棋谱面板右上角有「保存」「读取」「▲」「▼」四个按钮。
- 点「保存」把当前这盘棋存成一个文件；点「读取」会列出所有存档（显示保存时间和手数），点其中一条即可接着下。
- 存档统一放在程序同级的 **`棋局存档`** 文件夹里，文件名形如 `棋局_2026-11-24_15-30-05.json`，换台电脑直接把这个文件夹拷走就行。
- 快捷键：`S` 保存，`L` 读取。

## 全屏 / 窗口

- 按 `F` 或暂停菜单里的「全屏：开 / 关」按钮随时在全屏和 660×1000 窗口之间切换。
- 布局按画布尺寸重新计算，窗口模式下布局同样跟随。
- 无论全屏还是小窗口，棋谱面板都在棋盘下面，不会压住棋盘。

## 规则实现

全部中国象棋规则，无简化：

- **蹩马腿**：马走日字时，靠近身体的那个格子被占据则不可走
- **塞象眼**：相走田字时，田字中心有子则不可走
- **炮需炮架**：炮吃子必须隔且仅隔一个棋子
- **象士不可过河**：红相黑象限制在各自半场
- **兵过河可横走，且永远不可后退**
- **将帅限九宫**：只能在 3×3 的宫内活动
- **飞将**：将帅照面即视为被将军
- **将军 / 将死 / 困毙**：无棋可走同样判负
- **和棋**：三次重复局面，或 60 回合（120 半步）无吃子
- **中文记谱**：前/后/中 + 进/退/平，如「炮二平五」「马二进三」「前兵进一」

## AI 对手

- Alpha-Beta 剪枝 + 迭代加深 + 时间控制
- MVV-LVA 走法排序（优先吃大子）
- 静态评估：子力价值 + 位置价值 + 攻王子力 + 将军状态
- 搜索末段静止搜索（只搜吃子，避免吃子后被反吃）
- 后台线程运行，界面不卡顿
- **不会来回走同一手**：搜索时回避走出已经出现过的局面，搜索到三次重复直接按和棋算；悔棋之后 AI 会换一种走法，不会原地打转
- AI 无棋可走时（将死 / 困毙）会直接判出结果，不会卡在「电脑回合」不动

难度：简单（深度 2 / 1 秒）、困难（深度 5 / 2.2 秒）。

## 操作

| 操作 | 说明 |
|---|---|
| 左键 | 点自己的棋子选中，再点目标位置落子 |
| 右键 | 取消选择 |
| 滚轮 | 在棋谱面板上上下翻记录 |
| `R` | 重新开始 |
| `U` | 悔棋 |
| `H` | 提示（AI 推荐一手） |
| `S` | 保存当前棋局 |
| `L` | 打开存档列表 |
| `M` | 切换人机 / 双人模式 |
| `F` | 全屏 / 窗口切换 |
| `Esc` | 打开 / 关闭暂停菜单 |
